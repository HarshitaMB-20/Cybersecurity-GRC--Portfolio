## Project 2 – ISO 27001 ISMS Implementation

**Organization:** Averix Technologies Pvt. Ltd. (Fictional Company)

This project expands on my previous Cybersecurity Risk Assessment by developing a proposed Information Security Management System (ISMS) for the same fictional SaaS-based HRMS company.

The project covers:

- Understanding the organization's business context and interested parties.
- Defining the ISMS scope.
- Establishing information security policies and responsibilities.
- Developing a risk assessment methodology and risk treatment plan.
- Preparing a Statement of Applicability (SoA).
- Mapping ISO 27001 controls to NIST CSF 2.0.
- Creating an ISMS implementation plan.
- Planning internal audits, monitoring, and management reviews.

**Skills Demonstrated:** ISO 27001:2022, ISMS Development, GRC Documentation, Risk Management, Statement of Applicability, NIST CSF 2.0, Internal Audit Planning, Continual Improvement.
